# Проверка обновлённого портфолио

10 сентября 2026 года. Локальный HTTP-сервер, настоящий headless Google Chrome через Playwright 1.63.0. Автоматический аудит axe-core 4.13.0. Исходный код проверен `npm run check`.

Полный финальный прогон `tests/browser.cjs` завершился успешно (13 групп проверок):

- 3D не загружается на первом экране; локальные изображения декодируются; все внутренние якоря существуют, повторяющихся ID нет.
- Скоринг: границы уровней 20/21 и 54/55, крайние значения, вес ML 0/100, нижняя граница от правил, округление половин как в Python и ввод с клавиатуры.
- Выбор технологий, реальные ссылки в панели, переход к кейсу, вращение стрелками.
- Пауза останавливает всю сцену; возобновление работает и при фокусе на кнопке.
- Axe: 0 обнаруженных нарушений WCAG 2 A/AA и 2.1 A/AA на desktop и mobile. Это автоматическая проверка, не полноценный ручной аудит со скринридером.
- Нет горизонтального переполнения при ширинах 320, 390, 768, 1024, 1440 и 1920 px.
- Мобильное касание выбирает технологию, видимые подписи не перекрываются, отмена жеста завершает drag.
- Reduced motion отключает автоматическое движение; изменение настройки поддерживается без перезагрузки.
- Сцена не делает WebGL draw calls вне экрана.
- При отключённом JavaScript доступны проекты и все 27 пунктов навыков; контролы демонстрации выключены, статический пример виден.
- Сбой загрузки модуля, отсутствие WebGL и потеря контекста оставляют понятное сообщение и полный список навыков; ресурсы потерянной сцены освобождаются.
- Нет необработанных ошибок JavaScript в обычных desktop/mobile сценариях.

Визуально просмотрены первый экран, коллаж NEBERI и сфера на desktop/mobile. Автоматические скриншоты сохраняются в `/tmp/portfolio-checks` при каждом запуске тестов.

Сайт не публиковался. Проверка поведения в Safari/Firefox и на физических телефонах не проводилась. Публичный NEBERI-стенд не ответил в пределах 15 секунд; на странице используются ссылка на исходники и локальная демонстрация логики. Репозитории кейсов не запускались — источники содержания описаны в `content-sources.md`.

## Изменения после последнего прогона

По просьбе автора новые проверки отложены. После зафиксированного выше прогона увеличены мобильные зоны нажатия и изменена высота сферы в landscape. Затем убрано автоматическое скрытие подписей сферы, добавлены анимации появления, hover-эффекты, фоны секций и SVG-курсоры. Результаты предыдущего прогона не подтверждают эти последние изменения. Проверка отсутствия наложений заменена в тесте проверкой постоянной видимости всех подписей; тест пока не запускался.

Следующая правка: порядок наложения CSS2D-подписей зафиксирован через уникальный renderOrder; глубина управляет непрерывной opacity без исключений для hover/выбора. Фоны подписей сделаны полупрозрачными. Розовые курсоры добавлены для grab/grabbing. Появление текста смягчено; две фоновые циклические анимации управляются общей кнопкой, reduced motion, видимостью страницы и первого экрана. Проверки этих изменений по прежней просьбе автора пока не запускались.
