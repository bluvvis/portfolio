# Grigorii Belyaev / portfolio

Статическое портфолио Григория Беляева: full-stack + ML. Имя — основной личный бренд, `bluvvis` используется только как GitHub username и технический идентификатор XP-среды. HTML, CSS, JavaScript; Three.js загружается отдельно при приближении к разделу навыков. Для публикации не нужна сборка.

Дизайн — авторская интерпретация Windows XP в чёрно-розовой палитре: рабочий стол, окна, меню «Пуск» и панель задач. Основной сценарий остаётся обычной прокруткой; все проекты открыты сразу, ярлыки работают одним нажатием.

## Локальный просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173. Открытие `index.html` через `file://` не подходит для ES-модулей сферы; обычное содержание при этом остаётся доступным.

## Файлы

- `index.html` — содержание, проекты и полный список навыков. `data-skill`, `data-category`, `data-description`, `data-projects` задают данные технологии. Атрибут `data-sphere` включает её в 3D-карту. `data-projects` содержит существующие ID кейсов через пробел.
- `style.css` — базовая система стилей.
- `motion.js` — вступительная постановка первого экрана, появление остальных окон и текста, подсветка под курсором и отклик кнопок; учитывает reduced motion, фокус и остановку анимаций.
- `xp-theme.css` — XP-тема портфолио: обои, оформление окон, панель задач, адаптивность.
- `desktop.js` — меню «Пуск», активный раздел на панели задач, копирование email.
- `skills-3d.css` — сфера, панель выбранной технологии и список навыков.
- `portfolio.js` — время Иннополиса, демонстрация скоринга, прогресс прокрутки и отложенная загрузка сферы.
- `skills-3d.js` — визуализация, выбор технологии, остановка вне экрана и освобождение ресурсов.
- `vendor/` — локальные модули Three.js и CSS2DRenderer.
- `assets/` — предоставленные автором фотографии, SVG favicon, курсоры и авторские векторные обои. Пиксельные иконки интерфейса находятся в SVG-спрайте внутри `index.html`.
- `docs/content-sources.md` — источники фактов и причины отбора проектов.

Основной текст и ссылки доступны без JavaScript. Сбой загрузки модулей или отсутствие WebGL не скрывают список навыков. При reduced motion сфера остаётся неподвижной; вручную её можно вращать мышью, касанием или стрелками при фокусе на области сцены. В обычном режиме hover и focus не останавливают вращение. Выбор технологии даёт обязательную паузу на 0,5 секунды, после которой движение указателя возобновляет сферу. Кнопка над сценой позволяет вручную остановить и продолжить автоматическое вращение. Подписи не скрываются при вращении: глубина передаётся размером и прозрачностью. Порядок наложения подписей постоянный, фоны полупрозрачные; полный список расположен ниже.

Кнопка «Анимации: вкл/выкл» на первом экране управляет автоматическим движением и запоминает выбор. Новый вход без якоря и обновление страницы наверху запускают постановку примерно на 16 секунд: `BLACK → BIOS/POST → COMPONENTS → BLACK → Grigorii XP → BLACK/VIDEO → FLASH → DESKTOP → bluvvis.exe → SYSTEM READY`. POST неравномерно проверяет CPU, память, графику, накопитель, сеть, звук и ввод; отдельный экран поднимает компоненты портфолио, а XP marquee проходит около четырёх с половиной циклов. После появления desktop задача `bluvvis.exe` остаётся неактивной, а главное окно, фото и терминал скрыты. Курсор переводит задачу через состояния hover и press; только фактическое нажатие запускает раскрытие главного окна из taskbar со скоростью, уменьшенной на 35%, затем появляются заголовок, фото и терминал. Разделы проектов, стека, профиля и контактов при первом появлении проходят собственный короткий системный рендер. Крупная системная кнопка `SKIP BOOT →` и клавиша Escape сразу показывают готовый интерфейс; случайный клик, касание или прокрутка загрузку не обрывают. Обновление из середины страницы восстанавливает прежнюю позицию без заставки; переход по якорю и системная настройка reduced motion также её пропускают.

## Проверки

Зависимости нужны только для разработки и тестирования:

```sh
npm install
npx playwright install chromium
npm run check
```

С работающим локальным сервером в другом терминале:

```sh
npm test
```

Можно использовать установленный Chrome:

```sh
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm test
```

Тесты проверяют якоря, изображения, границы скоринга, выбор технологий, паузу, возобновление, клавиатуру, касания, отсутствие переполнений, reduced motion, остановку вне экрана, отключённые JS/WebGL и WCAG A/AA через axe. Скриншоты и результаты axe сохраняются в `/tmp/portfolio-checks`; путь переопределяется `SCREENSHOT_DIR`, адрес сайта — `BASE_URL`.

## Публикация

Разместить `index.html`, `style.css`, `skills-3d.css`, `xp-theme.css`, `portfolio.js`, `skills-3d.js`, `desktop.js`, `motion.js`, `assets/` и `vendor/` на статическом HTTP(S)-хостинге с корректными MIME-типами JavaScript. Домен не задан: canonical/og:url и абсолютный og:image следует добавить после выбора адреса. Шрифты загружаются с Google Fonts; при недоступности используются системные альтернативы.

Демо NEBERI иллюстрирует конкретную часть публичной логики: смесь правил и ML с нулевым дополнительным бонусом, Python-совместимое округление и `max(смесь, правила)` для присвоения уровня риска. Оценки вводятся вручную; ML-модель в портфолио не запускается.

## Поведение XP-оболочки

- Ярлыки и кнопки панели задач — обычные ссылки на разделы, без двойного клика.
- «Пуск» — дополнительная навигация на широком экране. Закрывается по Escape, нажатию вне меню и выбору раздела. Стрелка вверх на кнопке переводит фокус в меню.
- Кнопки в заголовках окон выполняют реальные действия: открыть исходники, увеличить фото или вернуться на рабочий стол. Обязательных окон входа, ожидания загрузки и перетаскивания нет.
- На телефоне окна выстраиваются в одну колонку; верхнее меню и дублирующий «Пуск» скрыты, а в панели задач доступны «Проекты», «Мой стек», «Обо мне» и «Связь». Активный раздел определяется прокруткой.
- Шрифты: Oswald для крупных заголовков, IBM Plex Sans для основного текста и XP-интерфейса, JetBrains Mono для терминала и технических подписей. Основная палитра строится на графите, белом/сером и насыщенном розовом для бренда, активных состояний и основных действий. Внутри 3D-карты сохранено отдельное цветовое кодирование категорий: frontend — розовый, backend — голубой, ML/data — янтарный, delivery/tests — зелёный. В остальном интерфейсе дополнительные цвета не используются как декор.
- Первый экран собирается как загрузившийся XP-рабочий стол. BIOS и XP разделены настоящими чёрными кадрами; перед desktop проходит короткая бело-розовая вспышка. Панель задач фиксируется первой, ярлыки загружаются группой, курсор активирует `bluvvis.exe`, а окно раскрывается из реальной позиции его задачи. `FULL-STACK + ML.` появляется после рамки и titlebar; фото и терминал запускаются как дополнительные приложения. После короткого `System ready` постановочные эффекты полностью прекращаются, остаются часы, терминальный caret и реакции на действия пользователя.
- Загрузку можно осознанно пропустить кнопкой `SKIP BOOT →` или клавишей Escape. Обычный клик, касание и прокрутка заставку не обрывают.
- При прокрутке главное окно физически уменьшается к кнопке «Проекты» на панели задач, а боковые окна и ярлыки уходят раньше. Раздел проектов открывается своей существующей сценой.
- Окна остальных разделов появляются один раз, но у них разные сценарии: главный проект раскрывается из строки заголовка, карточки входят стопкой, карта навыков запускается круговой маской и сканером, профиль собирается навстречу из двух колонок, контакт появляется как новое письмо. Эффекты отключаются общей кнопкой и reduced motion, при скрытии вкладки останавливаются.
- Кнопка копирования email появляется только при поддержке Clipboard API.
- После обновления страницы позиция чтения восстанавливается по ближайшему разделу или проекту и смещению внутри него. Новое открытие сайта начинается как обычно.
- Тема вынесена отдельно для дальнейшей настройки. Полный возврат к предыдущему дизайну — через сохранённую пользователем версию в Git: структура первого экрана также изменена.

XP-версия проверена в Chrome и мобильном WebKit; результаты и границы проверки — в `docs/validation.md`.

Начальные позиции подготавливаются за экраном, запуск происходит при входе в видимую область. Движение родителей не дублирует движение дочерних блоков. В «Как я работаю» текст один раз набирается по буквам с курсором. Исходный текст остаётся в документе для вспомогательных технологий; при отключении движения или уходе блока за экран набор завершается сразу. Высота строк сохраняется во время печати.

В начале проектов есть быстрые переходы к кейсам. Детали архитектуры NEBERI раскрываются через нативный `details`; описание роли и результата видно сразу. Дубли навигации внутри первого окна и контактов убраны.

Контакты на desktop используют две колонки: крупное приглашение и карточку связи. На мобильном они располагаются друг под другом. Прокрутка к ссылкам и фокусу учитывает нижнюю панель задач.
